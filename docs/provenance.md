# Code Provenance and Attribution

The SageMath source was mechanically extracted from the author-supplied research notebook. Notebook outputs and the invocation cell were excluded. The extraction did not change algorithms, parameters, formulas, domain-separation constants, or experiment functions.

The MATLAB scripts and `.mat` files were selected from the author-supplied security-analysis directory according to their correspondence with figures and experiments in the manuscript. The `.mat` files were generated by the author's SageMath/Python experiment code; MATLAB is used for selected post-processing and visualization rather than for generating the cryptographic experiment data.

No third-party source file, copyright header, or embedded third-party license was found in the selected SageMath or MATLAB files. The implementation follows the publicly documented HQC construction at the algorithmic level, but it is a reduced-scale SageMath reimplementation and does not contain the official HQC C source tree.

HQC specifications and official implementations remain subject to their own notices and licenses. Users who introduce code from the official HQC implementation, SageMath examples, MATLAB File Exchange, or another repository must preserve the corresponding attribution and license terms. The repository's MIT License does not override a third party's license.
